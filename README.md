# S1 System

Dana의 상따 전략을 반복 실행하기 위한 **키움 REST API 실전 주문 시스템**입니다. 종목을 예측하는 기능보다 진입·손절·익일 청산·성과 기록·비중 통제에 집중합니다.

## 구현된 전략

- 거래 가능 시간 기본값 `08:00–20:00`
- 거래대금 상위 종목 스캔 후 시가총액·거래대금 필터
- 기본 `+29.0%` 도달 시 시장가 진입
- 실제 평균단가 기준 사용자 지정 손절률
- 익일 NXT 08:00 / KRX 09:00 / 자동 판단 청산
- 동일 종목 당일 재진입 금지
- 실제 적용 비중 `90% / 180% / 270%`
- 최근 실적 기반 추천 비중과 실제 적용 비중 분리
- SQLite 거래 기록과 최근 5·10·20회 성과 대시보드

## 중요한 안전 구조

저장소를 실행했다고 주문이 바로 나가지 않습니다. 실제 주문에는 아래 세 단계가 모두 필요합니다.

1. 키움 운영 App Key/Secret 연결
2. `.env`에서 `LIVE_TRADING=true`
3. 대시보드에서 `S1 LIVE` 입력 후 실주문 활성화

App Key, Secret, 계좌정보, 토큰과 로컬 DB는 `.gitignore`로 제외됩니다.

## 설치

키움 공식 런타임 기준에 맞춰 Python 3.13 이상과 `uv`를 권장합니다.

```bash
uv sync --extra dev
uv tool install kwcli
kiwoomcli setup
cp .env.example .env
```

`kiwoomcli setup`에서 `real(실전투자)` 프로필을 연결한 뒤 `.env`를 열어 `LIVE_TRADING=true`로 바꿉니다. 키움 공식 권장 방식대로 App Key/Secret은 운영체제 자격 증명 저장소에 두며, `.env`에 키를 중복 저장하지 않는 편이 안전합니다.

CLI 인증 대신 `.env` 방식을 쓰는 경우에는 운영용 `APP_KEY`와 `APP_SECRET`을 `.env`에 입력한 뒤 서버를 완전히 재시작하세요. `.env.example`은 실행 시 읽지 않습니다.

## 실행

```bash
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000
```

브라우저에서 `http://127.0.0.1:8000`을 엽니다.

## 추천 비중 규칙

현재 기본 규칙은 “빠르게 낮추고 천천히 높이기”입니다.

- `90%`: 연속 3패 또는 최근 기대값 -1% 이하
- `180%`: 연속 2패 또는 최근 기대값 0% 이하, 혹은 표본 축적 중
- `270%`: 최근 10회 승률 60% 이상이면서 기대값 양수

추천치는 자동 계산되지만 실제 적용 비중을 덮어쓰지 않습니다. 대시보드에서 Dana가 최종 확정합니다.

## 실제 사용 전 확인

- 키움 `ka10032`의 거래대금은 기본적으로 백만원 단위로 환산합니다. 계정 응답의 단위를 확인하고 다르면 `KIWOOM_TRADING_VALUE_UNIT_WON`을 조정하세요.
- 270% 주문은 미수 가능 금액과 종목별 증거금률에 따라 거절될 수 있습니다. 시스템은 목표 주문금액을 키움의 20% 주문가능금액 이하로 제한합니다.
- NXT 대상 여부는 키움 `ka10100` 응답으로 판단합니다.
- 주문 API는 키움 공식 `kt10000`(매수), `kt10001`(매도)을 사용합니다.
- 공식 문서도 주문 코드는 실전 전에 검토와 테스트 환경 검증을 권고합니다. 최소 주문수량으로 체결·평균단가·NXT 청산시간을 먼저 확인하세요.
